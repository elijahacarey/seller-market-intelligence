# Seller-Market-Intelligence

A local application that exports publicly available Etsy marketplace data using the Etsy Open API.

The purpose of this project is to help Etsy consultants and shop owners make better business decisions through data-driven analysis.

## Purpose

This tool is designed to support Etsy business consulting by collecting publicly available marketplace information including:

- Shop information
- Active listings
- Product catalogs
- Pricing
- Categories
- Images
- Inventory (when available)
- Listing metadata

The exported data can be analyzed to better understand:

- Competitive positioning
- Product assortment
- Pricing strategies
- Catalog depth
- Brand positioning
- Merchandising
- Growth opportunities
- Marketplace trends

The goal is to provide Etsy sellers with objective market insights that help improve their businesses.

## Features

- Export multiple Etsy shops
- CSV export
- Bulk shop processing
- Image metadata
- Listing metadata
- Inventory export
- Product property export
- Local processing
- No cloud storage

## Example Use Cases

- Competitive benchmarking
- Etsy shop consultations
- Product assortment analysis
- Pricing analysis
- Market research
- Category analysis
- Brand comparisons
- Product portfolio reviews

## Technology

- Python
- Streamlit
- Pandas
- Etsy Open API v3

## Data Source

This project uses the official Etsy Open API.

No Etsy webpages are scraped.

## Disclaimer

This project is intended for market research, business consulting, and educational purposes using publicly available marketplace information exposed through Etsy's official API.

Users are responsible for complying with Etsy's API Terms of Use.
